1. Crear la solución
mkdir MMORPG-DDD
cd MMORPG-DDD

-Crear solución:
dotnet new sln -n MMORPG

2. Crear proyecto de dominio
mkdir src
cd src
dotnet new classlib -n Dominio

Agregar proyecto a la solución:
cd ..
dotnet sln add .\src\Dominio\Dominio.csproj

3. Crear proyecto API
dotnet new webapi -n Api
-Agregar API a la solución:
dotnet sln add .\Api\Api.csproj
-Referenciar Dominio desde Api:
dotnet add .\Api\Api.csproj reference .\src\Dominio\Dominio.csproj

4. Crear estructura de carpetas
Entrar al proyecto Dominio:
cd .\src\Dominio

Crear carpetas:
mkdir Abstracciones
mkdir Compartido
mkdir Jugadores
mkdir Partidas
mkdir Inventario
mkdir Objetos

-Crear carpetas de eventos:
mkdir .\Partidas\Events
mkdir .\Inventario\Events

5. Eliminar archivo Class1.cs
del Class1.cs
